# Loan-Portfolio-Analysis

Bank Loan Analysis & Reporting | Excel Project


## Project Overview

This project focuses on analyzing bank loan data using Microsoft Excel to evaluate lending performance, identify financial trends, and provide insights into loan portfolio quality.

The analysis covers 38,576 loan records and uses Excel Pivot Tables, KPI calculations, and data visualization techniques to transform financial data into meaningful business insights.


## Tools & Technologies

Microsoft Excel – Data analysis and reporting

Pivot Tables – Data aggregation and summarization

Pivot Charts – Data visualization

Excel Formulas – Financial calculations and KPI analysis


## Key Performance Indicators (KPIs)

The project evaluates several financial performance metrics:

Total Loan Applications: Number of loan applications.

Total Funded Amount: Total value of loans issued.

Total Amount Received: Total payments collected.

Average Interest Rate: Average interest rate across loans.

Average Debt-to-Income Ratio (DTI): Assessment of borrowers' debt levels relative to their income.

Month-to-Date (MTD) Analysis: Evaluation of monthly loan performance.


## Data Analysis

The analysis focuses on:

Loan Performance: Classification of loans into Good Loans and Bad Loans.

Monthly Trends: Examination of loan application volumes over time.

Loan Status: Analysis of repayment and loan status categories.

Customer Financial Profiles: Evaluation of annual income, employment length, and home ownership.

Loan Characteristics: Analysis of loan purposes, interest rates, loan grades, and repayment terms.


## Project Highlights

Analyzed 38,576 loan records using Excel.

Created Pivot Tables to summarize financial and customer data.

Calculated key banking KPIs to evaluate loan portfolio performance.

Examined monthly lending trends and loan repayment patterns.

Organized financial data to support reporting and data-driven decision-making.


## Project Objective

The main objective of this project is to demonstrate how Microsoft Excel can be used to analyze financial datasets, monitor banking KPIs, and generate actionable business insights.

The project highlights practical skills in data analysis, financial reporting, KPI monitoring, and business intelligence.
